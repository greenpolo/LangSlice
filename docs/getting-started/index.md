# Getting started

These pages take you from nothing installed to an AI app that can use
LangSlice. You do them once per computer.

| Step | What you do |
|---|---|
| 1. [Install LangSlice](install.md) | Install Miniforge, then LangSlice itself. This downloads several gigabytes. |
| 2. [Connect your AI app](connect.md) | Install the app for the AI you already use, then add LangSlice to it. |

You need:

- a computer running Windows, macOS or Linux, with about 15 GB of free disk
  space;
- an internet connection;
- an account with ChatGPT, Gemini or Claude. A free ChatGPT or Gemini
  account works. Claude needs a paid plan.

You will type a few commands into a **terminal**, the window where you type
commands for the computer instead of clicking. Every command is given in
full: copy it, paste it, and press **Enter**.

```{toctree}
:maxdepth: 1

install
connect
```
