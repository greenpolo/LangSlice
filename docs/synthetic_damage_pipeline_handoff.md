This note captures the current workflow for improving LangSlice synthetic slice damage, plus the state of the most recent implementation work. It is written for the next agent/session so work can continue without re-discovering the visual and code context.

## Goal

We are QC-ing real histology slices for SFT/RLVR data and using those failures to improve the synthetic data pipeline. Many manually registered real slices have unreliable coordinates, so the training set should rely more heavily on synthetic examples with realistic damage.

The immediate damage targets are:

- Deliberate hemibrain preparations, where one hemisphere is removed and the remaining hemisphere is centered.
- Posterior coronal lateral "wing" damage, where one or both lateral posterior slabs detach or disappear.

The user explicitly corrected an earlier interpretation: this is not just missing isocortex. The target is the whole lateral wing, including cortex plus hippocampal/cortical-subplate-adjacent tissue. The central brain mass should remain intact.

### HemibrainPreparation

`HemibrainPreparation` removes one whole hemisphere and shifts the retained side toward the canvas center.

Behavior:

- Applies to coronal and horizontal planes.
- Skips sagittal.
- Updates `ctx.tissue_mask`, `ctx.annotation_slice`, `ctx.density_map`, and `ctx.tissue_class_masks`.
- Runs early in `apply_damage_layer` before microtome/slide artifacts.

Pipeline probability currently:

```python
HemibrainPreparation(p=_p(0.08))
```

### PosteriorWingDamage

`PosteriorWingDamage` fully replaces the old `PosteriorIsocortexDropout` idea.

Behavior:

- Applies only to coronal posterior slices.
- Requires `ctx.position_mm >= 8.5`.
- Skips if a thalamus mask is present and nonempty.
- Samples wing states:
  - one wing missing
  - both wings missing
  - both wings detached/offset/angled
  - one wing missing and the other detached

Wing selection currently works like this:

1. Build an eligible source mask from atlas tissue classes where available:
   - `isocortex`
   - `hippocampal_formation`
   - `cortical_subplate`
2. Use the full tissue silhouette only to compute the centerline.
3. Split eligible tissue into lateral left/right candidates using a curved boundary.
4. Keep only connected components that reach the outer tissue edge. This prevents central medial strips from being treated as wings.

This last point came from a bug found by the user: the first silhouette-only heuristic cut out a portion of the main brain. The current regression test is `test_posterior_wing_damage_preserves_medial_core_shoulder`.

Pipeline probability currently:

```python
PosteriorWingDamage(p=_p(0.30))
```

## Tissue Class Additions

`classify_tissue` now includes these specific masks in addition to broad tissue classes:

- `isocortex`
- `thalamus`
- `hippocampal_formation`
- `cortical_subplate`

These are used by posterior wing damage. The broader `get_tissue_id_sets` behavior remains focused on gray matter, white matter, and ventricles.

## Context Plumbing

`TransformContext` now carries:

```python
plane: str = "coronal"
position_mm: float | None = None
```

These are threaded through all renderer entrypoints and `synth_dataset.py`. This matters because posterior wing damage must be gated by actual AP position and plane.

CLI coronal paths pass:

```python
plane="coronal"
position_mm=ap_mm
```

## Important Lessons

- Do not rely only on tests for visual damage. Always open or inspect generated images.
- A silhouette-only lateral heuristic can wrongly select central posterior tissue.
- The user wants biological/physical plausibility more than a named atlas region. The damage should look like tissue preparation/handling, not like an atlas mask deletion.
- Detached wings should be visibly separated by a gap and optionally slightly rotated/shifted.
- Missing wings should preserve the central brain mass.
