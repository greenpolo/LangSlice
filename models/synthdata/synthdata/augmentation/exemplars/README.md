# Style Exemplar Library

These are hand-curated real-histology crops used as style references during Stage B (diffusion fallback) generation. Selection criteria: clean staining, anterior/middle/posterior coverage, no severe artifacts. Modalities: DAPI, Nissl, brightfield, fluorescence, ISH. Counts and provenance are tracked in the (gitignored) `_local/exemplar_provenance.md`.
